# 📸 Photos Harmonie

Organisation de la bibliothèque visuelle. Voir `04_IMAGE_GENERATION.md` §3.

```
photos/
├── reference/     ← le set CURÉ : vraies photos du bateau & du terroir, propres et nommées.
│                    C'est ici que je pioche pour générer (mode image→image, Pilier 7).
├── generated/     ← les images produites par Nano Banana (sorties du script).
└── CATALOG.md     ← l'index que je tiens à jour (sujet, orientation, piliers, émotions).
```

## Comment ça marche

1. **Tu déposes** tes photos en vrac (idéalement sur le Drive « Harmonie – Photos »,
   ou directement ici dans `reference/`).
2. **Je trie** : je regarde chaque image, je la décris, je garde les meilleures,
   je les renomme proprement et je remplis `CATALOG.md`.
3. **Je génère** : quand tu demandes un visuel, je vais chercher tout seul la bonne
   photo dans le catalogue et je la passe à Nano Banana.

## Ce qui fait une bonne référence
Belle lumière naturelle/dorée · cadrage net · le **vrai** 12 m sous plusieurs angles
(pont, proue, carré, vue d'ensemble) · détails de vie à bord (table dressée, lin, coussins).
