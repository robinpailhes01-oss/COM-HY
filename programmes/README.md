# 🗓️ Programmes mensuels

Le **seul input récurrent** dont j'ai besoin pour générer un post/story (cf. `04_IMAGE_GENERATION.md` §1).

## Comment faire
Deux options, au choix :
1. **Me le dire en message** (« voici le programme de juillet : … »).
2. **Déposer un fichier** ici, nommé `AAAA-MM.md` (ex. `2026-07.md`), avec le contenu du mois.

## Que mettre dedans
Tout ce qui définit l'offre du mois — je m'occupe de le traduire en émotion :
- Les sorties / créneaux / occasions (couchers de soleil, journées, privatisations…)
- Les nouveautés ou attentions spéciales du mois
- Dates clés (fête des mères/pères, 14 juillet, événements locaux…)
- Tarifs / conditions → **pour mon contexte uniquement**, jamais affichés tels quels sur le feed (cf. `03`).

Je m'occupe du reste : pilier, émotion, photo, prompt, image, légende, hashtags.
